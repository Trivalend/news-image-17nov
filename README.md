A program that draws a newspaper front page summing up the world's news of Tuesday 17 November 2026: the US-Iran escalation in the Gulf, the Kerch Bridge strike, the Shenzhen trilateral summit, Gaza's winter crisis, the COP31 deal and the US measles milestone — as a single 1024x1024 PNG, drawn from scratch with a hand-written 5x7 bitmap font and a pure-stdlib PNG encoder. No network, no randomness: two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
